派特皇家學院 V2.1 日期修改版

安裝順序：
1. 先備份目前 Netlify 正常使用的 V2.0 部署版本。
2. 登入 Supabase > SQL Editor，執行 V2.1_先執行.sql。
3. 確認 SQL 執行成功後，先用測試預約驗證日期修改、撞期阻擋、房型額滿與課程保留。
4. 將本 ZIP 重新部署到 Netlify，登入後在預約的「修改課程／接送」內可找到「修改預約日期」。

注意：新增加的日期沿用學院、選修及舊票卡課程文字，但不自動加購游泳；未變動日期保留原課程；被移除日期的課程會刪除。
本版已做 JavaScript 語法檢查，但未連線至實際 Supabase 專案進行整合測試。請勿在正式預約上直接首次測試。
